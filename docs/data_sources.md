# LankaHarvest — Data Sources

## 1. Paddy Yield Dataset

**Source organization:** Sri Lanka Department of Census and Statistics (confirm original download link).

**Source URL:** To be added.

**Coverage:** 1978–2025 (Maha starting years), 1979–2025 (Yala).

**Geographical coverage:** 25 Sri Lankan districts.

**Files used:**
- Average_Yield-Maha_Season-1979-2025.xlsx
- Average_Yield-Yala_Season-1979-2025.xlsx

**Selected variables:**
- District
- Cultivation year
- Cultivation season
- Total average paddy yield (kg/ha)

**Processing:** Extracted the Total yield column from each cultivation season and combined the records using Pandas.
